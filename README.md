# enesayaz.github.io

Personal site of Enes Ayaz, built with the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme for Jekyll.

- **Blog post:** copy `_drafts/post-template.md` to `_posts/YYYY-MM-DD-title.md`.
- **Publication:** add an entry at the top of `_data/publications.yml`.
- **News:** edit `_data/news.yml`.
- **Research:** edit `_data/projects.yml`.
- **CV:** edit `_tabs/CV.html`.
- **Animation:** add a script in `assets/js/animations` and a page in `_animations`.
- **Photo:** replace `assets/img/avatar.jpg` (sidebar) and `assets/img/portrait.jpg` (home page).

Pushing to `master` builds and publishes the site. GitHub Pages must use "GitHub Actions" as its source.
